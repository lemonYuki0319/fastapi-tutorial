## 一、中间件简介

### 1.1 什么是中间件？

中间件是一个函数，在每个请求到达接口处理函数之前和之后执行。

**执行流程**：
```
请求 → 中间件（前） → 接口处理函数 → 中间件（后） → 响应
```

### 1.2 中间件的作用

- ✅ 请求日志记录
- ✅ 请求计时
- ✅ 跨域处理（CORS）
- ✅ 请求过滤
- ✅ 统一响应处理
- ✅ 性能监控

## 二、基本中间件

### 2.1 使用 @app.middleware 装饰器

```python
from fastapi import FastAPI, Request, Response
import time

app = FastAPI()


@app.middleware("http")
async def log_requests(request: Request, call_next):
    """
    请求日志中间件
    
    - request: 请求对象
    - call_next: 调用下一个中间件或接口处理函数
    """
    # 请求前：记录请求信息
    start_time = time.time()
    print(f"[请求] {request.method} {request.url}")
    
    # 调用下一个处理函数
    response = await call_next(request)
    
    # 请求后：记录响应信息
    process_time = time.time() - start_time
    print(f"[响应] 状态码: {response.status_code}, 耗时: {process_time:.3f}s")
    
    # 添加自定义响应头
    response.headers["X-Process-Time"] = str(process_time)
    
    return response


@app.get("/")
def root():
    return {"message": "Hello World"}
```

### 2.2 中间件执行顺序

```python
from fastapi import FastAPI, Request

app = FastAPI()


@app.middleware("http")
async def middleware1(request: Request, call_next):
    print("中间件1 - 前")
    response = await call_next(request)
    print("中间件1 - 后")
    return response


@app.middleware("http")
async def middleware2(request: Request, call_next):
    print("中间件2 - 前")
    response = await call_next(request)
    print("中间件2 - 后")
    return response


@app.get("/")
def root():
    print("接口处理函数")
    return {"message": "Hello"}


# 执行顺序：
# 中间件1 - 前
# 中间件2 - 前
# 接口处理函数
# 中间件2 - 后
# 中间件1 - 后
```

## 三、常用中间件示例

### 3.1 请求计时中间件

```python
from fastapi import FastAPI, Request
from time import time

app = FastAPI()


@app.middleware("http")
async def add_process_time_header(request: Request, call_next):
    """添加处理时间响应头"""
    start_time = time()
    response = await call_next(request)
    process_time = time() - start_time
    
    # 添加到响应头
    response.headers["X-Process-Time"] = f"{process_time:.4f}"
    
    return response
```

### 3.2 请求日志中间件

```python
from fastapi import FastAPI, Request
from datetime import datetime
import json

app = FastAPI()


@app.middleware("http")
async def log_request_middleware(request: Request, call_next):
    """记录请求日志"""
    # 记录请求信息
    log_data = {
        "timestamp": datetime.now().isoformat(),
        "method": request.method,
        "url": str(request.url),
        "client": request.client.host if request.client else None,
        "user_agent": request.headers.get("user-agent", "")
    }
    
    print(f"[请求日志] {json.dumps(log_data, ensure_ascii=False)}")
    
    # 处理请求
    response = await call_next(request)
    
    # 记录响应信息
    log_data["status_code"] = response.status_code
    print(f"[响应日志] 状态码: {response.status_code}")
    
    return response
```

### 3.3 IP 黑名单中间件

```python
from fastapi import FastAPI, Request, Response
from fastapi.responses import JSONResponse

app = FastAPI()

# IP 黑名单
BLACKLIST = ["192.168.1.100", "10.0.0.50"]


@app.middleware("http")
async def ip_filter_middleware(request: Request, call_next):
    """IP 过滤中间件"""
    client_ip = request.client.host if request.client else None
    
    # 检查是否在黑名单
    if client_ip in BLACKLIST:
        return JSONResponse(
            status_code=403,
            content={"code": 403, "message": "IP 被禁止访问"}
        )
    
    return await call_next(request)
```

### 3.4 请求体大小限制中间件

```python
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse

app = FastAPI()

# 最大请求体大小（字节）
MAX_BODY_SIZE = 1024 * 1024  # 1MB


@app.middleware("http")
async def limit_body_size(request: Request, call_next):
    """限制请求体大小"""
    # 只检查有请求体的方法
    if request.method in ["POST", "PUT", "PATCH"]:
        content_length = request.headers.get("content-length")
        if content_length and int(content_length) > MAX_BODY_SIZE:
            return JSONResponse(
                status_code=413,
                content={"code": 413, "message": "请求体过大"}
            )
    
    return await call_next(request)
```

## 四、CORS 跨域处理

### 4.1 什么是 CORS？

CORS（Cross-Origin Resource Sharing，跨源资源共享）是一种浏览器安全机制，用于限制网页从不同源（域名、协议、端口）请求资源。

**跨域场景**：
- 前端：http://localhost:3000
- 后端：http://localhost:8000
- 端口不同，属于跨域

### 4.2 CORS 错误示例

```
Access to XMLHttpRequest at 'http://localhost:8000/api' from origin 
'http://localhost:3000' has been blocked by CORS policy: 
No 'Access-Control-Allow-Origin' header is present on the requested resource.
```

### 4.3 使用 CORSMiddleware

```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

# 配置 CORS
app.add_middleware(
    CORSMiddleware,
    
    # 允许的源（域名）
    allow_origins=[
        "http://localhost:3000",
        "http://localhost:8080",
        "https://example.com"
    ],
    
    # 或允许所有源（开发环境可用，生产环境不推荐）
    # allow_origins=["*"],
    
    # 允许的凭证（Cookie）
    allow_credentials=True,
    
    # 允许的 HTTP 方法
    allow_methods=["*"],  # 允许所有方法
    
    # 允许的请求头
    allow_headers=["*"],  # 允许所有请求头
    
    # 暴露给前端的响应头
    expose_headers=["X-Total-Count", "X-Process-Time"],
    
    # 预检请求缓存时间（秒）
    max_age=600,
)


@app.get("/api/data")
def get_data():
    return {"message": "跨域请求成功"}
```

### 4.4 CORS 参数详解

| 参数 | 说明 | 示例 |
|------|------|------|
| `allow_origins` | 允许的源 | `["http://localhost:3000"]` |
| `allow_origin_regex` | 允许的源（正则） | `r"https://.*\.example\.com"` |
| `allow_methods` | 允许的方法 | `["GET", "POST"]` 或 `["*"]` |
| `allow_headers` | 允许的请求头 | `["*"]` |
| `allow_credentials` | 允许携带凭证 | `True` |
| `expose_headers` | 暴露的响应头 | `["X-Total-Count"]` |
| `max_age` | 预检缓存时间 | `600` |

### 4.5 开发环境 vs 生产环境

```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
import os

app = FastAPI()

# 根据环境配置 CORS
if os.getenv("ENV") == "production":
    # 生产环境：严格限制
    allow_origins = [
        "https://example.com",
        "https://www.example.com"
    ]
else:
    # 开发环境：允许所有
    allow_origins = ["*"]

app.add_middleware(
    CORSMiddleware,
    allow_origins=allow_origins,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

## 六、自定义中间件类

### 6.1 继承 BaseHTTPMiddleware

```python
from fastapi import FastAPI, Request
from starlette.middleware.base import BaseHTTPMiddleware
from time import time

app = FastAPI()


class TimerMiddleware(BaseHTTPMiddleware):
    """计时中间件类"""
    
    async def dispatch(self, request: Request, call_next):
        # 请求前
        start_time = time()
        
        # 调用下一个处理函数
        response = await call_next(request)
        
        # 请求后
        process_time = time() - start_time
        response.headers["X-Process-Time"] = f"{process_time:.4f}"
        
        return response


# 添加中间件
app.add_middleware(TimerMiddleware)
```

### 6.2 带配置的中间件

```python
from fastapi import FastAPI, Request
from starlette.middleware.base import BaseHTTPMiddleware
from typing import List

app = FastAPI()


class IPFilterMiddleware(BaseHTTPMiddleware):
    """IP 过滤中间件"""
    
    def __init__(self, app, blacklist: List[str] = None, whitelist: List[str] = None):
        super().__init__(app)
        self.blacklist = blacklist or []
        self.whitelist = whitelist or []
    
    async def dispatch(self, request: Request, call_next):
        client_ip = request.client.host if request.client else None
        
        # 黑名单检查
        if client_ip in self.blacklist:
            from fastapi.responses import JSONResponse
            return JSONResponse(
                status_code=403,
                content={"code": 403, "message": "IP 被禁止访问"}
            )
        
        # 白名单检查（如果配置了白名单）
        if self.whitelist and client_ip not in self.whitelist:
            from fastapi.responses import JSONResponse
            return JSONResponse(
                status_code=403,
                content={"code": 403, "message": "IP 不在白名单中"}
            )
        
        return await call_next(request)


# 添加中间件（带配置）
app.add_middleware(
    IPFilterMiddleware,
    blacklist=["192.168.1.100"],
    whitelist=None  # 不使用白名单
)
```

## 七、完整示例

```python
from fastapi import FastAPI, Request
from fastapi.middleware.cors import CORSMiddleware
from fastapi.middleware.gzip import GZipMiddleware
from fastapi.middleware.trustedhost import TrustedHostMiddleware
from fastapi.responses import JSONResponse
from time import time
from datetime import datetime
import json

app = FastAPI(
    title="FastAPI 中间件示例",
    version="1.0.0"
)


# 1. CORS 中间件
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # 开发环境允许所有
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
    expose_headers=["X-Process-Time", "X-Total-Count"],
)


# 2. 信任主机中间件
app.add_middleware(
    TrustedHostMiddleware,
    allowed_hosts=["*"]  # 开发环境允许所有
)


# 3. GZip 压缩中间件
app.add_middleware(
    GZipMiddleware,
    minimum_size=1000,
    compresslevel=6
)


# 4. 请求日志中间件
@app.middleware("http")
async def log_middleware(request: Request, call_next):
    """请求日志中间件"""
    # 记录请求
    log_data = {
        "timestamp": datetime.now().isoformat(),
        "method": request.method,
        "url": str(request.url),
        "client_ip": request.client.host if request.client else None
    }
    print(f"[请求] {json.dumps(log_data, ensure_ascii=False)}")
    
    # 处理请求
    response = await call_next(request)
    
    # 记录响应
    print(f"[响应] 状态码: {response.status_code}")
    
    return response


# 5. 计时中间件
@app.middleware("http")
async def timer_middleware(request: Request, call_next):
    """请求计时中间件"""
    start_time = time()
    response = await call_next(request)
    process_time = time() - start_time
    
    # 添加处理时间到响应头
    response.headers["X-Process-Time"] = f"{process_time:.4f}s"
    
    # 慢请求警告
    if process_time > 1.0:
        print(f"[警告] 慢请求: {request.url} 耗时 {process_time:.4f}s")
    
    return response


# 6. 异常处理中间件
@app.middleware("http")
async def error_handler_middleware(request: Request, call_next):
    """全局异常处理中间件"""
    try:
        return await call_next(request)
    except Exception as e:
        print(f"[错误] {str(e)}")
        return JSONResponse(
            status_code=500,
            content={
                "code": 500,
                "message": "服务器内部错误",
                "detail": str(e)
            }
        )


# 接口
@app.get("/")
def root():
    """根路径"""
    return {
        "message": "Hello World",
        "timestamp": datetime.now().isoformat()
    }


@app.get("/slow")
def slow_api():
    """模拟慢接口"""
    import time
    time.sleep(1.5)
    return {"message": "慢接口响应"}


@app.get("/error")
def error_api():
    """模拟错误接口"""
    raise Exception("模拟错误")


@app.get("/large-data")
def large_data():
    """返回大量数据（测试 GZip）"""
    return {"data": "x" * 10000}
```

## 十、常见问题

### Q1: CORS 配置后仍然报错？

检查以下几点：
1. `allow_origins` 是否包含前端地址
2. `allow_credentials` 为 True 时，`allow_origins` 不能为 `["*"]`
3. 前端请求是否携带了自定义请求头

### Q2: 中间件执行顺序？

中间件按添加顺序的**逆序**执行：
- 后添加的中间件先执行"前"部分
- 先添加的中间件先执行"后"部分

### Q3: 如何在中间件中读取请求体？

```python
@app.middleware("http")
async def read_body(request: Request, call_next):
    # 读取请求体
    body = await request.body()
    
    # 注意：读取后需要重新设置
    # 因为 request.body() 只能读取一次
    return await call_next(request)
```
